# Lessons Log

> **TL;DR:** Append-only, dated lessons — each entry `✅/⚠/❓`-labeled with its evidence. The project's canonical lessons home.

Format for entries (append at the end, newest last; never rewrite history — corrections become new entries):

```markdown
- ✅ — **Title of the lesson (YYYY-MM-DD, context).** What happened, what was learned,
  the rule going forward. Evidence: file, command output, or commit.
```

Rules:

1. Append-only. A wrong lesson is corrected by a new entry that names it, not by editing it.
2. One lesson per bullet; if an entry needs its own page, it belongs in `pitfalls.md` or `docs/` with a pointer here.
3. Evidence or ❓ — no unlabeled claims.
4. Distill recurring lessons into [pitfalls.md](pitfalls.md); the log keeps the history, the pitfalls file keeps the current truth.
