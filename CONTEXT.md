# CONTEXT — domain vocabulary for the kbase repo

> **TL;DR:** The words this repo uses, so code, docs, and reviews stay on one vocabulary. New terms land here when they crystallize.

- **Knowledge note** — one markdown file under `knowledge/` in a scaffolded repo. The unit `ksearch` retrieves and the gate polices.
- **Current note** — a note in scope: under `knowledge/`, `.md`, not in `archive/` or `*-archive/`, not in `plans/artifacts/`, not `_`-prefixed. Declared once in `scripts/kbformat.py` (`is_current_md`).
- **TL;DR** — the `> **TL;DR:** …` blockquote within the first 10 lines of a note; the strongest ranking field and a birth requirement the gate enforces.
- **The format module (`kbformat`)** — the deep module behind the note format: TL;DR convention, current-note scope, field split, and the KB status-line grammar. `ksearch`, `knowledge-gate`, and `kbase-init` all import it; none re-implements it.
- **The gate (`knowledge-gate`)** — the pre-commit module validating staged knowledge state: plan `## Status`, anti-truncation, TL;DR-at-birth + link-at-birth, KB status-line rules.
- **ksearch** — BM25 search over current notes; ranked excerpts, not whole files.
- **KB status line** — `SCAFFOLDED @ <sha>` / `VERIFIED @ <sha>` in `knowledge/README.md` + `INDEX.md`; written and parsed through `kbformat`'s shared grammar.
- **Bootstrap brief** — `knowledge/_bootstrap-brief.md`, generated by init in existing mode: the evidence pack plus a pointer to the distill procedure. Deleted at the flip.
- **Distillation (`distill`)** — the SCAFFOLDED → VERIFIED pass; canonical procedure in `knowledge/practices/skills/distill.md` (stubs and the brief point at it).
- **kb-audit** — the consolidation loop (query-log review, label spot-check, reference audit, splits); canonical procedure in `knowledge/practices/skills/kb-audit.md`.
- **Scaffold** — this repo's `template/` tree that `kbase-init` copies into target repos.
